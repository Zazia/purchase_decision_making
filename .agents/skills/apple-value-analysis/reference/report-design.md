# 报告模块:图表规范、视觉纪律与报告结构

> 加载条件:进入主流程步骤7(输出报告)前必读。
> **所有可复制代码(CSS token、组件伪代码、ECharts baseOption 与图表模板、禁止事项)的唯一权威源为 constants.json `design_tokens` 字段**——生成 HTML 报告时直接复用该字段中的代码块,不擅自修改数值;新增图表类型时仍必须合并 `baseOption` 模板。

## 1. 通用要求

- 每张图必须有:标题、横轴名、纵轴名、数据来源、阅读说明
- 移动端字号≥14px,桌面端≥12px

## 2. 绘制技术栈

- **图表库**:ECharts(CDN引入)
- **输出格式**:单个自包含HTML文件
- **输出位置**:当前项目工作目录,文件名格式:`YYYY-MM-DD-苹果产品购买决策报告.html`(如`2026-08-27-苹果产品购买决策报告.html`)
- **移动端适配**:viewport设置+响应式容器

## 3. 视觉纪律(不依赖任何外部设计文件)

- **品牌蓝 `#007AFF` 是唯一的行动指向色**:推荐行/前沿点/关键数字/链接。推荐行高亮用 `--accent-soft`,不用 `success-soft`
- **语义色只进徽章,不大面积填充**;仅 4 种语义色(success/warning/error/default),不新增
- **前沿点/主数据线永远是品牌蓝**;被支配点用灰色半透明(`C_GRAY` + `opacity:0.5`)
- **超支持期边框用 `C_WARNING`(橙)**,不用红色——红色留给"被支配"语义
- **长持有期(>36月)的点用 `opacity:0.6`** 标注预测置信度低
- **不引外部字体 CDN,不引 Tailwind/Bootstrap 等 UI 框架**;字体栈见 constants.json `design_tokens.字体栈`
- **不用深色/渐变背景、斑马纹表格、3D 效果、多层阴影叠加、动态动画**(除 tooltip 外)
- **图表高度**:核心图(帕累托)430px / 辅助图 330px / 移动端统一 360px
- **关键数字(月均成本等)不进徽章**,直接用 `font-size:32px;font-weight:600;font-family:var(--font-display)`

## 4. 标准图表类型

**图表1:保值率曲线图**(折线图)
- 横轴:机龄(发布后月数)
- 纵轴:保值率%

**图表2:帕累托前沿图**(散点图,核心图表)
- 横轴:月均成本(元/月)→ 越低越省
- 纵轴:持有期平均性能满足度% → 越高越好
- 每个点 = 一个(机型 × 持有期)候选方案
- **前沿点**:实心圆+品牌色,用虚线连接表示前沿
- **被支配点**:空心圆+灰色,标注"已排除"
- **硬约束排除点**:不显示(已在步骤1排除)
- 气泡大小:持有期内净支出(买入价 - 残值 + 维修成本),反映资金占用规模
- 标注:用户性能地板(若有)用水平虚线,预算上限(若有)用垂直虚线,截取前沿上的推荐区间用高亮色
- 不确定性标注:长持有期(>36月)的点用半透明或虚线边框,标注"预测置信度低"
- **等待方案标注**:类型B/C方案用不同形状(如三角形)或标签"等新品后"区分,标注"预测值"。等待月数在图例中说明

**图表3:各机型多持有期成本曲线**(折线图,辅助图表)
- 横轴:持有月数(12/18/24/36/48/60)
- 纵轴:月均成本
- 每个机型一条线
- 用于展示"持有越久月均越低但边际递减"的趋势

## 5. 报告结构(四部分,结论先行)

**第一部分:结论与推荐方案**
- 一句话结论:买什么、怎么买、持有多久
- 推荐方案表(仅含前沿上截取的推荐区间):型号、配置、**买入时机**(现在/等新品后)、买入价、持有期、月均成本、平均性能满足度、推荐理由
- 前沿备选清单:前沿上其他非劣方案,供用户按偏好选择
- **等待方案提示**:若包含类型B/C方案,标注等待月数和"预测值",提示用户评估等待期机会成本(如无设备可用期间的替代方案)

**第二部分:支撑证据**
- 帕累托前沿图(核心图表)
- 完整候选方案计算表(含被支配点及剔除原因)
- 宏观因素分析
- 常量校验结论(含校验级别)
- 维修成本估算明细

**第三部分:图表说明**
- 帕累托前沿图的阅读方法
- 前沿上各点的含义
- 不确定性标注说明

**第四部分:更新提示**
- 触发重新分析的条件(如:新品发售后2周实测二手价偏离加权中枢±10%触发重分析;实测保值率与曲线偏差>10pp标注"实测偏差提示")
- 下次建议分析时间
