# 市场采样模块:数据源优先级、筛选规则与置信度

> 本模块是市场价搜索与快照更新的执行细则。加载条件:场景路由 R3(快照需黄色/红色更新,或采样疑似污染)。
> 快照分级判定(绿/黄/红)在 SKILL.md 步骤3.0;本模块只管"如何搜、如何筛、如何标注、如何回写"。

## 1. 数据源优先级

从 agent 自主操作优先、尽量减少用户介入的角度,严格按以下优先级执行(见 constants.json "实时市场价快照._数据源优先级"):

**一级_苹果官网直采**(高置信度,agent 自主,无需用户介入):
- 苹果官网(apple.com.cn)静态 HTML 价格可 WebFetch 直接获取 → 优先使用,用于当前同品类新品价(原"残值分母",v4.3 起仅信息展示/类型B价格预测基准)和当前在售机型的官方价

**二级_可信二手资料**(中置信度,agent 自主,无需用户介入):
- 一级无法获取二手价时,WebSearch 搜索**明确写了购买日期+购买渠道+完整配置的真实成交帖**,且与宏观事实不冲突。可信来源优先级:V2EX/Reddit/什么值得买用户实付晒单 > B站视频实拍 > 论坛讨论
- **5项标准**(必须全部符合):见 constants.json "实时市场价快照._可信二手资料5项标准"

**三级_browser-use直采销售渠道**(中置信度,需用户协助登录):
- 一二级均无法获取足够数据时,使用 browser-use subagent 访问闲鱼/爱回收等销售渠道
- **适用平台与搜索策略**:按 constants.json "实时市场价快照._browser_use_最佳实践" 字段执行(含前提条件、搜索策略、关键词精确化、筛选规则、步骤预算、回写快照规则)

**四级_兜底**(无法搜索):
- 标注"无法搜索(无符合标准的可信二手资料)",不得编造。**必须在报告中明确提示用户人工补充或检查**,建议用户提供具体闲鱼/爱回收/京东链接或截图(置信度可升至高)

## 2. 当前同品类新品价(原"残值分母")——完整定义

> v4.3(2026-09-02)起残值改为买入价锚定(SKILL.md 步骤5),本字段不再参与残值计算,仅用于类型B买入价预测基准与报告信息展示;"同芯片级别"取值口径继续有效。

指该品类当前在售的最新一代**同芯片级别**产品的官方售价:
- "同芯片级别"定义:基础芯片对应当前最新基础芯片,Pro 对应当前最新 Pro,Max/Ultra 以此类推
- 例1:Mac mini M2(基础芯片) → 取"Mac mini M6(基础芯片)官方售价"(6999元;原M4口径5999作历史值保留)
- 例2:Mac mini M2 Pro(Pro芯片) → 取"Mac mini M5 Pro官方售价"(Mac mini无M6 Pro,Pro级最新为M5 Pro);若最新一代无对应芯片级别(如某代无Pro),则用该品类当前最高配置官方售价
- **注意**:不是该机型自身的原始发布价

**取值方法**:优先查 constants.json "实时市场价快照"对应品类的"官方价"字段(已 WebFetch 过则直接使用);若无,执行 WebFetch 搜索苹果官网对应品类页面。

## 3. 候选机型买入价搜索与筛选

**操作**:对候选机型清单,从 constants.json "实时市场价快照"对应品类下查各机型价格。快照中已有的字段直接使用;缺失或需更新的字段按 §1 数据源优先级搜索补充。

**价格筛选规则**:
- 搜索结果中的价格必须明确标注完整配置(芯片+内存+存储),不同配置价格不可混用
- 排除无效数据:引流帖(标价极低但实际无货)、翻新机冒充二手、官翻机混入、资讯稿/导购评测文引用价(不符合5项标准)、卖家挂单价(非实付交易)
- **同代配置价格倒挂校验**:二手采样价须与同代更高配置款交叉校验——标准款/低配款价格高于同代Pro/高配款即判污染(混入高配挂单或引流样本),剔除后重新采样。列表页批量采样(如闲鱼搜索结果快照)尤其必做,单条目逐个核验易漏。实证:iPhone 16 256G旧采样5875元与16 Pro(5400元)倒挂,2026-08-26判定污染并修正为4000元(3源交叉)
- 取有效数据的中位数作为参考价,记录样本量和价格区间
- **合理区间校验**:二手价应在同品类当前新品价的15%-85%之间(视机龄调整)。机龄12月内应在70-85%;24-36月应在45-65%;48-60月应在15-35%。超出区间需二次验证
- **置信度标注**:按 constants.json "实时市场价快照._置信度等级"字段评定(高/中/低)
- **AC+说明**:参考价默认指不带Apple Care+的裸机价;若用户计划购买AC+,需将AC+费用按持有月数平摊计入月均成本

**配置精确化**:
- 8G与16G版本价差约20-30%,不得混用
- 256G与512G版本价差约15-25%,不得混用
- 若某配置数据不足,可基于相近配置按比例估算,标注"估算"

**置信度低的字段处理**:
- 在分析报告中**必须明确标注**置信度等级,不得作为精确决策依据
- 对缺失或低置信度的关键字段,**主动提示用户人工补充或检查**(如"⚠️Mac mini M2 16G二手闲鱼价为低置信度(论坛讨论非实付),建议用户提供具体闲鱼/爱回收链接或截图以提高置信度")
- 若用户提供具体闲鱼/爱回收/京东链接或截图,优先使用用户提供的数据(置信度可升至高)

## 4. 电商折扣价(仅限当前在售机型)

**搜索方法**(从快照中读取或 WebSearch 补充):
1. 京东自营价:查快照"京东自营价_参考"字段,或 WebSearch 搜索 `"{具体型号} 京东 自营 价格 {当前年}"` 寻找符合5项标准的实付晒单
2. 京东国补到手价:查快照"京东国补到手价"字段,或 WebSearch 搜索 `"{具体型号} 国补 到手价 {当前年}"` 寻找符合5项标准的实付晒单
3. 京东以旧换新到手价:查快照"京东以旧换新到手价"字段,或 WebSearch 搜索

**国补/临时补贴处理**:
- 月均成本计算使用**用户实际支付价(补贴后)**作为买入价
- 报告中单独标注补贴金额和政策时效性风险

## 5. 快照回写

若本步骤执行了新的搜索,将搜索结果回写到 constants.json "实时市场价快照"对应品类/机型字段,并更新 snapshot_date 为本次搜索日期。**预测值(类型B/C买入价)不得回写**(SKILL.md 禁忌11),快照仅记录实际搜索到的真实价格。

## 6. 变量搜索与时效规则

- 二手价同一配置至少3个独立报价(或符合5项标准的可信二手资料单样本,标注中置信度)
- 所有价格通过合理区间校验
- 电商价以京东自营为准,国补使用实付价
- **优先使用 constants.json "实时市场价快照"中的已搜索价格**,仅对缺失/过期/低置信度字段做补充搜索
- 优先级:真实交易渠道直采(苹果官网WebFetch) > 符合5项标准的可信二手资料(实付晒单) > 兜底标注"无法搜索"并提示用户人工补充
- 变量标注搜索日期,时效30天
- 常量按三级校验规则更新(绿/黄/红);年度更新每年1月进行
