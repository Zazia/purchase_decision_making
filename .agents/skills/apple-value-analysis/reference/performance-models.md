# 性能模型模块:推算口径、变体折算与新品性能预测

> 本模块是新品性能预测与推算跑分处理的**权威定义位置**(SKILL.md 步骤4 只列核心公式与操作,不重复细则)。
> 加载条件:场景路由 R2(候选含已官宣未发售新品,其跑分为推算值)。
> 主流程步骤4的 S(0)/S̄(N) 公式与 r 取值不在此重复。

## 1. 官宣未发售窗口的性能数据处理

**适用判定**:分析时点新品芯片已官宣但未发售,其跑分为推算值(constants.json 芯片条目带"_实测说明"且标注"推算值/待实测回填")。与定价模块同窗口互补:pricing-scenarios.md 管该窗口的**价格**不稳定(三情景),本模块管**性能**数据不确定(推算区间)。

### 核心规则

1. **基准芯片保留实测口径**:品类基准芯片(性能系数分母)保持最后一个**实测**旗舰,不用推算芯片做基准。理由:分母若用推算值,其估算误差会传导到该品类全部老款系数且不确定性被隐藏;保留实测基准,误差只落在新芯片自身一项、且显式可见
   - 例外:推算置信度高的条目可提前切换(如按历史倍率推算的 Ultra 融合芯片,Mac_Pro 基准已随 M5 Ultra 官宣切至推算口径),以 constants.json "品类基准芯片"当前口径为准
2. **新芯片自身系数允许 >100%**:系数 = 推算跑分 ÷ 实测基准跑分,可超过100%(表示超出当前实测旗舰),S(0)/S̄(N) 照常代入衰减公式。例:M6 推算多核 21000 ÷ M5 实测 17100 ≈ 123%
3. **区间敏感性(必做)**:用推算区间两端分别计算新芯片 S(0),报告标注如"S(0)=123%(推算区间120-127%,待实测回填)"。若区间两端使帕累托前沿的**推荐方案发生改变**,必须输出两种口径的前沿对比,不得只给点值
4. **报告标注**:凡性能计算用到推算跑分的候选,在推荐方案表与性能图表中标注"⚠️ 跑分为推算值,待实测回填"

### 实测回填触发(发售日后,新芯片 Geekbench 实测入库时)

1. 回填跑分条目并删除"推算值"标注
2. 品类基准芯片切换为新芯片,该品类全体系数重算
3. M系列 r 值统一重算(M6 推算期暂缓,见 §4)
4. 若某老款候选 S(0) 因基准切换变化超过 ±5 个百分点、或推荐方案排序改变,在报告"更新提示"注明"性能基准已切换,建议复核"

基准切换会使该品类全系 S(0) 绝对值下移(相对最新旗舰的口径变化),但候选间**相对排序不变**(比值不变),帕累托结论通常稳定——报告复核提示中说明这一点,避免误读为"老款突然变差"。

## 2. 变体折算

芯片条目内含变体说明(如"_15核变体说明")时,分析对应基础款须按说明折算跑分——Mac mini M5 Pro 基础款按多核 25892 而非条目值 28500 计算,直接用条目值会高估系数约 10%。

## 3. 类型B性能预测细则(主流程步骤4第3条展开)

- **未官宣**:新品为新的基准芯片,S(0)=100%;新品跑分预测 = 当前最新旗舰跑分 × (1+r)^(发布周期月/12);S̄(N) = [100% + 100%/(1+r)^(N/12)] / 2
- **已官宣未发售**:按本模块 §1 推算口径处理,基准保持实测不切换
- **代际跃升模型调整**:查 constants.json "芯片代际提升假设" 对应系列的"per_generation详表",若新品信号符合"跃升代际"(架构大改/节点成熟期/核心数增加),将下一代预测的提升率上调至 r×1.5;若为节点首发代际(如2nm/3nm首发),下调至 r×0.5

## 4. r 值依据与说明

- r 为基于历史跑分的 CAGR(复合年增长率),非 per-generation 简单平均:M系列 0.16(基于M1→M5实测跑分与发布间隔重算),A系列 0.15(基于A14→A19)。per-generation 年化率波动:M系列 9-28%,A系列 6-26%,实际代际提升有较大波动
- M系列 r=0.16 基于 M1→M5;M6 为推算值且 M5→M6 间隔仅5月年化失真,暂不重算,待 M6 实测后统一重算
- 代际跃升识别:详表记录 M1→M2(+31%,跃升)、M3→M4(+25%,跃升)等显著代际;节点首发代际(如A16→A17_Pro仅+6%,3nm首发)反而提升最小,因良率受限
- 近期趋势:M4→M5 仅10%/年,显示放缓迹象;M6 已官宣(2026-08-25),2nm首发判断命中,绝对提升+20%(官方口径),但 M5→M6 间隔仅5月使年化≈49%/年——趋势判断需绝对提升率与年化双口径;M7/A21(2nm成熟)可能成为下一跃升代际(年化20%+)
- 长持有期(>36月)的衰减预测置信度降低,需在报告中标注
- 此衰减仅反映"相对性能落后",不反映"绝对性能下降"——M2今天能做的事3年后一样能做,只是相对新旗舰显得落后

## 5. 数值示例

M2 16G 256G(M系列):S(0)=48%(多核9700 ÷ M5实测基准17100=0.567,×16G内存权重1.0 × 256G存储权重0.85)。持24月:S(24)=48%/1.16²=36%,S̄(24)=(48%+36%)/2=42%;持36月:S̄=40%;持48月:S̄=38%。

M4 16G 256G:S(0)=75%(多核15000/17100=0.877,×0.85)。持24月:S̄=65%;持48月:S̄=58%;持60月:S̄=55%。
