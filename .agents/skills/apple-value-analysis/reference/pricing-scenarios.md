# 定价场景模块:涨价发布与等待新品(锚定-冲击双因子模型)

> 本模块是类型B/C买入价与失效判定规则的**权威定义位置**(SKILL.md 步骤1/步骤5 只作指针,不重复公式)。原"残值分母切换"规则已随 v4.3 残值买入价锚定废止(见 §6)。
> 加载条件:场景路由 R1(新品已官宣定价,锚涨幅超出 ±5%),或分析涉及等待新品候选(类型B/C)。
> 文中 "查 constants.json" 均指 SKILL.md 同目录的 constants.json。

## 1. 适用判定:发布形态

分析时点新品已官宣定价(或已发售)。先计算锚涨幅 = (新品官宣价 − 老款现行官方价) / 老款现行官方价,按区间分流:

| 发布形态 | 锚涨幅 | 处理 |
|---------|--------|------|
| 涨价发布 | > +5% | 启用本模块双因子模型(下文全部规则) |
| 平价换代 | −5% ~ +5% | 走主流程类型B/C逻辑,锚涨幅按 0 处理 |
| 降价发布 | < −5% | 走主流程逻辑,锚定项使二手预估更低 |

## 2. 核心模型

```
锚涨幅 = (新品官宣价 − 老款现行官方价) / 老款现行官方价      ← 对比现行官方价,非首发价
冲击幅度 = 品类冲击历史均值 × (1 + 价格传导因子)             ← 传导因子按锚涨幅查表
预估二手价 = 当前二手价 × (1 + 锚涨幅) × (1 − 冲击幅度 × 时变因子)
```

两股独立力量:锚上移抬升老款替代价值(利多),代际冲击压低老款(利空)。只含冲击项的公式只能表达"跌多少",无法表达涨价发布时的"不跌反涨",会系统性高估老款降幅与类型C捡漏空间。

## 3. 类型C:等新品后买降价老款

**买入价(权威公式)**:
```
买入价 = 当前老款市场价 × (1 + 锚涨幅) × (1 − 调整后冲击幅度 × 冲击时变因子)
```
- 锚涨幅:见 §2。新品未官宣定价时锚涨幅 = 0,公式退化为单一冲击项
- 调整后冲击幅度 = 品类冲击历史均值 × (1 + 价格传导因子);传导因子由锚涨幅查 constants.json "新品发布对老款冲击._宏观因子调整_v3.8._价格传导因子表";未触发宏观事件时使用原始均值
- 冲击时变因子:按"新品发布后到买入的月数"查 "._冲击时变曲线_v3.8" 的"买入价下降因子"(1月内=1.0,3月内=0.95,6月内=0.80,12月内=0.50,12月后=0.20)
- 买入时机龄 = 当前机龄 + 等待月数(含缺货延迟);持有期末机龄 = 当前机龄 + 等待月数 + 持有月数
- 残值按 v4.3 买入价锚定计算(残值 = 买入价 × R(卖出机龄)/R(买入机龄),买入机龄 = 当前机龄 + 等待月数),**不施加**新品冲击调整——冲击折扣已锚定在买入价中,经锚定公式自然传导至残值

**失效判定(涨价发布必做)**:三情景加权买入价 ≥ 当前市场价 → "等降价捡漏"逻辑失效——不生成类型C候选,或生成但在报告标注"⚠ 涨价发布,预估买入价不低于当前价,等待无收益"。

## 4. 类型B:等新品后买新品

- **已官宣**:买入价直接用官宣价,不再用预测涨幅外推(官宣后快照官方价已是新品价,再乘涨幅会重复计算);v4.3 残值 = 官宣买入价 × R(持有月数)/R(0)
- **未官宣且宏观触发"新品价格预测模型"**(存储超级周期/全线涨价事件):买入价 = 当前同档老款官方价 × (1 + 预测涨幅中位数),查 constants.json "新品发布对老款冲击._新品价格预测模型_v3.8._分品类预测涨幅表"
- **未触发**:回退"同档同价假设"
- **等待月数** = max(0, (预计发布年−分析年)×12 + (预计发布月−分析月)) + 上市到货延迟(月)。延迟查 constants.json "苹果产品发布节奏._缺货等待期模型_v3.8";存储超级周期_进行中时延迟 × 宏观产能因子(默认2.0,见顶中×1.5)。报告标注"基线等待月数"与"悲观等待月数"
- 性能:S(0)与S̄(N)规则见 reference/performance-models.md(同一窗口的 R2 路由)

## 5. 执行要点

1. **分档差异化(必查)**:同一产品线不同档次涨幅常分化,必须分档分别计算锚涨幅与传导因子,不得全线一刀切。例:2026-08 Mac mini 基础档锚涨幅 +16.7% → 传导因子 −25% → 冲击 38% 降至 28.5%;Pro 档锚涨幅仅 +4% → 因子 −5% → 冲击 36.1%——两档结论方向相反(基础款二手利多,Pro 档利空)
2. **三情景输出**(发布窗口期1-3月预估,输出区间而非点值):
   - 情景A 全额传导:冲击 × 时变因子全额落地,保守下界
   - 情景B 实证口径:取最近一次同类涨价发布事件的实测冲击,查 constants.json "新品发布对老款冲击._涨价发布实证参考_v4.1";无同品类事件时用形态最接近的跨品类事件并标注外推
   - 情景C 零冲击:锚定全额传导、冲击≈0,乐观上界(缺货+惜售环境)
   - 三情景概率加权得出中枢(参考权重 30%/45%/25%,按 §5.4 四问调整)
3. **概率赋值四问**(写入报告依据):①老款是否已停产/稀缺化?②新品缺货概率高吗(首发制程、存储周期、限购政策)?③需求端有无结构性增量(如本地AI)?④涨价前二手是否已透支一轮涨幅?——供货是决定性变量,预购/发售日的到货周期数据出现后,优先用其修正情景概率

## 6. 对购买决策的传导

> v4.3(2026-09-02)起残值改为**买入价锚定**(残值 = 买入价 × R(卖出机龄)/R(买入机龄),比率封顶1),下列原"残值分母"规则已废止,当前同品类新品价仅作信息展示与类型B价格预测基准保留。

1. **类型A残值**:持有期跨越发售日时,残值 = 买入价 × R(卖出机龄)/R(当前机龄) × (1 − 调整后冲击幅度 × 残值调整时变因子),冲击项用价格传导因子对冲后的幅度(原"分母切换"废止,涨价影响经冲击调整乘法体现)
2. **类型B/C残值**:直接按买入价锚定公式计算(类型B 买入机龄=0;类型C 买入机龄=当前机龄+等待月数),不涉及新品价分母;买入价本身的预测价/官宣价/快照价三情形取值见 §3/§4
3. **卖出时机标注**:用户持有老款且计划短期出手时,在报告"更新提示"标注"官宣至发售后首月为高位窗口"

## 7. 边界与禁忌

- 本模型预估的是**发布窗口期(1-3月)价格**,不修改保值率曲线;残值计算仍走主流程步骤5的买入价锚定公式
- 预测值不回写快照(SKILL.md 禁忌11);新品实际发布后用实测复核:发售后2周实测二手价偏离加权中枢超过 ±10% 时触发重分析——快照按红色全更新,用真实价格替换预测值,预测涨幅表对应品类标记为"已发生"
- 品类冲击均值与实证口径差距大时(如 Mac_mini 均值38%无实测来源),情景A与情景B天然分歧,必须输出区间而非点值
