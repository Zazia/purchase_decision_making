## 2. 数据来源与质量标准

沿用 constants.json 内已有的 `实时市场价快照._快照分级使用规则`：

**一级（高置信度）**：官方渠道现价——苹果官网 apple.com.cn、京东自营页面，WebFetch 直取。二手价无一级来源。

**二级（中置信度）**：可信二手资料——明确写了购买日期 + 渠道 + 完整配置的真实成交帖（V2EX/Reddit/smzdm 实付晒单 > B站实拍 > 论坛讨论），或媒体实测报道（smzdm、新浪财经、东方财富、头条）中给出具体价格数字的。

**三级（参考）**：转转研究院/回收宝/爱回收的季度二手市场报告（有汇总数据但常无具体机型时点价）。

**闲鱼挂单价**：非实付，实付价 ≈ 挂单价 × 0.9；采集方法见 §4.2；凡用挂单价必须标注"挂价口径"。

**冲击均值替换的质量门槛**（替换启发式均值为实测值的条件）：

- 门槛 A（可替换均值）：≥2 个独立来源相互印证，或 1 个权威来源（回收宝/转转研究院/爱回收报告、主流媒体含具体价格）+ 保值率曲线合理性交叉验证（实测冲击不应超出"代际跨越额外贬值 10-15%"量级太远，>30% 的值需额外证据）
- 门槛 B（只记录不改值）：单一事件单一来源 → 均值保持不变，在 `_数据来源` 字段记录"单一事件实测点"，并把该事件写入 `_涨价发布实证参考` 或新增 `_冲击实证点_v4.2` 收集字段
- 无数据 → 保持原值，标注"启发式预设,无实测来源（YYYY-MM-DD 检索未果）"

### 3.2 事件研究法（方法论）

核心思想：保值率曲线（本库已有、本身由数据统计得出）充当**反事实基线**——老款本来就会按曲线贬值；新品发布带来的"额外偏离"才是冲击。

```
实测保值率(t)   = 老款实测二手价 ÷ 该款官方参考价
曲线理论值(t)   = 保值率曲线[品类] 在机龄 t 处的值（月粒度插值）
实测冲击(t)     = 实测保值率(t) ÷ 曲线理论值(t) − 1
```

注意事项：

- **官方参考价口径**：用测量时点该款仍在售的官方价。若测量时点跨越了官方调价（如 2026-06-25 全线涨价），用调价后的现行官方价；定价链可查快照各条目"备注"
- **机龄 t**：从 `产品发布日期` 节取老款发布月，算到测量时点
- **挂价折扣**：闲鱼挂单价先 ×0.9 折成实付口径再算实测保值率；媒体报道的"二手价"若未说明口径，标注"口径未明"
- 每个事件尽量取 **T+1周 / T+2月 / T+6月** 三个时点；拿不到三个就记录拿到的
- **形态标注**：每个事件标注"涨价发布 / 平价换代 / 降价发布"（按新品价 vs 老款当时官方价，±5% 内算平价）。涨价发布形态的事件**同时**写入 `_涨价发布实证参考_v4.1` 节（追加新条目，格式对齐 iPhone_17_2025-09）
