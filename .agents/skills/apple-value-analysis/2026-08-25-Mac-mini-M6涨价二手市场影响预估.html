03传导机制：五股力量怎么作用于二手价

把「新品涨价发布」拆成可量化的两股主力和三股定性侧力，净方向取决于供货。

力量方向量化（基础档）机制说明
① 锚定效应利多+16.7%二手价锚定「当前在售新品官方价」。锚从 5,999 → 6,999，同配置二手的替代价值水涨船高。这是 6 月涨价后二手跟涨 50% 的同一机制。
② 代际冲击利空-28.5%（调整后）新品发布使老款相对性能落后+需求转移。Mac mini 历史冲击均值 38%（常量库口径）。
③ 涨价对冲利多冲击 38%→28.5%
（传导因子 -25%）		新品越贵，老款相对越便宜、性价比越凸显，冲击被部分抵消。涨幅 15-30% 对应传导因子 -25%。
④ 供给稀缺利多定性M4 已停产；M6 为 2nm 首发芯片+存储超级周期，首发缺货概率高（M4 时期曾官网全面售罄、翻新机溢价 60%+）；每人限购 2 台。
⑤ AI 需求增量利多定性本地 AI 推理需求（OpenClaw 等）自 2026 年起持续推高 Mac mini 需求曲线，6 月涨价后 M4 二手 +50% 中有相当部分来自此力。

05三情景量化预估

公式与参数全部来自常量库机制（新品冲击均值、价格传导因子表、冲击时变曲线），情景差异只在「冲击实际落地幅度」。

预估公式
预估二手价 = 当前二手价 × (1 + 锚涨幅) × (1 − 冲击幅度 × 时变因子) 锚涨幅 = (新品官方价 − 老款现行官方价) / 老款现行官方价 → 本次基础档 +16.7% 冲击幅度 = 冲击历史均值 × (1 + 价格传导因子) → 38% × (1−25%) = 28.5% 时变因子 = 发售后 1 月内取 0.95（3月内 0.85 / 6月内 0.60 / 12月内 0.30） 情景A（现货充足） : 冲击全额落地 28.5%×0.95 = 27.1% → 净 ×0.851（−15%） 情景B（温和缺货） : 冲击按 iPhone 17 实证 ≈ 3% → 净 ×1.132（+13%） 情景C（严重缺货） : 冲击 ≈ 0，锚定全额传导 → 净 ×1.167（+17%）

概率赋值 A 30% / B 45% / C 25%：依据——M6 为 2nm 首发+存储周期，缺货概率高，但 6,999 定价本身吸收了部分成本压力且抑制需求，缺货烈度大概率不及 M4 时期（当时 4,499 严重供不应求）；同时 6-7 月二手已透支一轮大涨（M4 +50%），继续大涨空间收窄。

Pro 档警示（M4 Pro / M2 Pro 二手持有者）：M5 Pro 12,999 仅比 M4 Pro 调价后官方价高 4%，属于「近乎平价换代」——按传导因子表（涨幅 0-5% → 因子 -5%），涨价对冲几乎为零，调整后冲击 36.1%，净效应约 -32%（全额传导口径）。缓冲因素：M5 Pro 基础款（15核，GB6 多核 25,892）与 M4 Pro 顶配（14核）CPU 跑分接近，代际压制弱于账面。综合预估二手 M4 Pro 发售后回调 -10% ～ -30%（现价无实测快照，理论推算约 8,400-8,800 元）。持有二手 Pro 档、计划一年内出手者，9-22 发售前后是最后的高位窗口。
中期路径（3-6 个月 / 12 个月）
  • 3-6 个月：若 M6 供货正常化（到货周期回到 1-2 周），老款向情景A 回归，回调 10-15%；若存储超级周期延续（行业预期 2027-2028 才缓解），高位横盘、按曲线斜率缓慢阴跌（43 月后约 -0.5%/月）。
  • 12 个月：当前二手价位大概率是「周期顶部区域」。但回落至 2026-06 涨价前水平（M4 丐版 3,000）需要同时满足「M6 现货敞开 + 存储周期缓解 + AI 需求退潮」三个条件，概率低于 20%。
  • 对买家：等 9-22 发售观察 M6 到货周期再决策，几乎无机会成本——最坏情形（情景C）也不过比现在贵 17%，而情景A 可以便宜 15%。
  • 对卖家：8-27 预购至 9-22 发售之间的「官宣窗口」情绪最好（惜售+涨价预期），是挂价窗口；发售后第一周成交数据出来前，建议用限高价挂出而非明盘。

06预估方法论：下次再遇到涨价发布，怎么算

五步法，参数全部可查常量库，输出区间而非点值。

步骤操作本次取值示例
1. 算锚涨幅新品官宣价 vs 老款现行官方价（不是 vs 首发价）6,999 / 5,999 − 1 = +16.7%
2. 查传导因子按新品涨幅查表，得到冲击折扣涨 15-30% → 因子 -25% → 冲击 38%→28.5%
3. 乘时变因子按「发售后到目标时点」查表1 月内 ×0.95 → 实际冲击 27.1%
4. 定性修正三问：老款停产了吗？新品会缺货吗？需求有结构性增量吗？基线透支了吗？停产✓ 缺货概率高✓ AI 需求✓ 已透支50%✓ → 概率向 B/C 倾斜但幅度收窄
5. 三情景输出全额传导 / 实证口径（找最近一次涨价发布的实测冲击）/ 零冲击，附概率-15% / +13% / +17%，概率 30/45/25

价格传导因子表速查：新品涨幅 ≤0% → +0%；0-5% → -5%；5-15% → -15%；15-30% → -25%；＞30% → -35%。冲击时变（残值口径）：1月内 0.95 / 3月内 0.85 / 6月内 0.60 / 12月内 0.30 / 12月后 0.10。

「实证口径」优先找同类事件：本次用了 iPhone 17（2025-09 涨价发布，老款冲击实测 2-4%）。若没有同类事件，用冲击均值全额口径作保守边界即可。
