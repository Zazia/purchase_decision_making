## v5.1(2026-08-27)防呆加固:引擎冒烟 + 信任边界 + 工具脚本

方法论、公式与数据无变化,针对"Agent 绕过 SOP 直读常量与引擎源码"的实测故障(2026-08-27 M6 官宣场景分析)新增防呆规则:

- 新增 `scripts/` 工具集(纯 Node 零依赖,随技能分发):
  - `query-constants.mjs`:constants.json 键路径查询(支持含点号键名的最长匹配、数组下标、`--list`/`--search`),成为常量查询唯一入口,替代"整读 1900+ 行文件 / rg 搜中文键"
  - `load-engine.mjs`:引擎加载器,内置 CJS 兼容垫片——实证 dist 产物为 CJS 语法但包声明 `"type":"module"`,直接 import 必失败(即 2026-08-27 排查日志 P0 根因),垫片方案复用自 `scripts/engine-diagnose-20260827.mjs`
  - `engine-smoke.mjs`:引擎冒烟检查(定位引擎 + 导出校验 + 真实微计算),步骤0 执行,PASS/FAIL 决定引擎或文字路径
- 引擎章节重构:「引擎调用(优先路径)」→「引擎调用(可选加速路径)」,明确引擎只是加速器、文字路径才是规格本身;新增**信任边界**(引擎黑盒 / 怀疑错误跑 pnpm test / 禁读禁改源码);删除"引擎实现细节见 packages/apple-value-engine/"的源码指引;调用示例由包名 import 改为 `loadEngine()` 加载
- 步骤0 新增引擎冒烟项;§2 开头新增**查询纪律**(禁整读 constants.json)
- 设计原则新增第 6 条**事实落盘与上下文恢复**(各步输出写 `analysis-facts.md`,压缩后只读该文件)
- 禁忌清单新增 12(禁整读常量)、13(禁读改引擎源码)
- 遗留提示(维护者向):引擎包 CJS/`type:module` 打包冲突为根治对象,修复后 `load-engine.mjs` 的垫片分支自然闲置,无需改动技能

**用户输入**:"想买个Mac mini,预算5000以内,不知道用几年划算"

**执行**:
1. 确定范围:单一品类Mac_mini。候选机型:[M1 16G, M2 16G, M4新品]。M2机龄42月。生成候选方案:每个机型 × {12,18,24,36,48,60}月。系统支持期标注:M2持48月(卖出时机龄90月>72月支持期)标注"⚠ 超出系统支持期18月";M2持60月标注"⚠ 超出42月"。均保留不排除
2. 常量校验:黄色轻校验。分层宏观扫描:L1检测到2026-06-25苹果全线涨价(Mac mini涨33.3%)+存储超级周期。L2判定为"存储超级周期_进行中"。L3搜索TechInsights BOM数据更新新品预测涨幅表。L4搜索Mac Studio缺货情况。激活v3.8机制清单:①新品价格预测模型启用;②冲击幅度向下修正;③缺货等待期因子=2.0。发布时间预测校验:Mac mini M5预测偏差已超1季度(原预测2026-Q3,实测无任何发布迹象),标注"⚠️ 类型B/C方案置信度降级"
3. 校验快照:查constants.json "实时市场价快照.Mac_mini",snapshot_date≤14天,直接使用快照价格。M2 16G二手2700元(参考价,低置信度,V2EX论坛讨论非实付),M4新品5999元(官方价WebFetch,高置信度),M1 16G二手1900元(参考价,低置信度,2025年3月数据超30天窗口)
4. 性能(用实测跑分):M2(M系列r=0.16)S(0)=48%(9700/17100(M5实测)=0.567,×16G×256G=0.567×1.0×0.85=48%)。持24月:S̄=42%;持36月:S̄=40%;持48月:S̄=38%。M4 S(0)=75%(M4多核15000/M5实测基准17100=0.877,×16G×256G=0.877×1.0×0.85=75%)。M4持24月:S̄=65%;持48月:S̄=58%;持60月:S̄=55%
5. 月均成本(启用宏观修正):M2持24月:残值计算用调整后冲击幅度38%×(1-0.25)=29%(新品涨价33%对应价格传导因子-25%),时变因子按24月对应0.30。残值720元,维修成本约200元(Mac mini年均故障100元×2年,无电池),月均(2800-720+200)/24≈95元。M2持48月:卖出时机龄90月(>72月⚠),保值率外推至72月约11%,残值5999×11%≈660元,维修成本400元,月均(2800-660+400)/48≈53元(标注⚠系统支持期风险)。M4持48月:卖出时机龄69月(当前机龄21月+48月),保值率外推约12.75%,残值5999×12.75%≈765元,维修成本400元,月均(5999-765+400)/48≈117元
6. 帕累托前沿:所有候选方案画散点。前沿上的点可能是:M2持24月(95元,42%)、M4持48月(117元,58%)、M4持60月(97元,55%)等。被支配点(如M1持24月被M2持60月支配)剔除。询问用户性能地板或给出三档参考
7. 输出报告:文件名`2026-08-02-苹果产品购买决策报告.html`,含帕累托前沿图。报告标注:⚠️ 当前处于存储超级周期,所有未发布新品价格用预测涨幅外推;Mac mini M5发布时间预测偏差已超1季度,类型B/C方案置信度降级
