# 设计令牌 — 规范化令牌源

> **层级：Layer 2** | 平台无关的令牌定义。各平台适配指南引用本文件的原始值并做单位换算。
>
> 上游入口：`design.md` → `.design_library/README.md` → **本文件**

本文件是项目所有视觉产物的**唯一令牌源**。颜色、字体、间距、圆角、阴影的数值在此定义一次，HTML 报告、小程序界面、Canvas 绘制各自引用。不要在业务代码中凭直觉取色或调间距——先查这里。

---

## 1. 色彩

### 1.1 中性色（9 阶）

工作面的基础。从浅到深，`#F5F5F7` 是页面背景，`#FFFFFF` 是卡片表面，`#1D1D1F` 是主文字。

| Token | HEX | 用途 |
|-------|-----|------|
| `gray-50` | `#F5F5F7` | 页面背景 |
| `gray-100` | `#E8E8ED` | 次级背景 / hover 压暗 |
| `gray-200` | `#D2D2D8` | 分隔线、边框 |
| `gray-300` | `#B9B9C1` | 禁用态边框 |
| `gray-400` | `#9E9EA8` | 占位文字 |
| `gray-500` | `#86868F` | 次级文字、说明 |
| `gray-600` | `#6E6E78` | 辅助文字 |
| `gray-700` | `#575760` | 强调次级文字 |
| `gray-800` | `#3F3F46` | 深色次级文字 |
| `gray-900` | `#1D1D1F` | 主文字 |

### 1.2 品牌蓝（主色）

承担界面中所有「行动指向」：主要按钮、链接、图表主数据线、激活态高亮。

| Token | HEX | 用途 |
|-------|-----|------|
| `blue-50` | `#E6F2FF` | 选中态背景 / accent-soft |
| `blue-100` | `#CCE4FF` | 浅蓝背景 |
| `blue-200` | `#99C9FF` | 信息图例 |
| `blue-300` | `#66ADFF` | 次级链接 |
| `blue-400` | `#3392FF` | hover 浅态 |
| `blue-500` | `#007AFF` | **主色** — 按钮、链接、图表主色 |
| `blue-600` | `#0063D4` | hover 态 |
| `blue-700` | `#004FAF` | pressed 深态 |
| `blue-800` | `#003B85` | 深色背景上的主色 |
| `blue-900` | `#00285C` | 极深蓝 |

### 1.3 语义色

仅用于徽章、状态标签、数据变化标识，**不大面积填充**。

| 语义 | Token | HEX（soft 背景 / 文字） |
|------|-------|--------------------------|
| 成功 | `green-600` / `green-100` | `#2A8A61` / `#D9F0E3` |
| 警告 | `amber-600` / `amber-100` | `#E09500` / `#FFF0C2` |
| 错误 | `red-500` / `red-100` | `#F24B4B` / `#FFD9D9` |
| 信息 | `cyan-600` / `cyan-100` | `#2BA3A6` / `#D7F5F5` |

> 项目补充语义色（小程序中使用）：
> - 二手标签：`#FFD9D9` 背景 / `#9F1239` 文字
> - 等待/候选标签：`#FFE9D1` 背景 / `#C25E00` 文字
> - 持有期标签：`#F5F5F7` 背景 / `#86868F` 文字

### 1.4 ECharts 调色板

图表数据系列颜色，按优先级排列。前沿点 / 主数据线**永远是品牌蓝 `#007AFF`**。

```
PALETTE = ['#007AFF', '#8E8E93', '#2A8A61', '#E09500', '#AF52DE', '#5856D6']
```

| 常量名 | 值 | 用途 |
|--------|-----|------|
| `C_PRIMARY` | `#007AFF` | 前沿点、主数据线 |
| `C_ACCENT_SOFT` | `#E6F2FF` | 选中区域填充 |
| `C_MUTED` | `#86868F` | 轴文字、图例 |
| `C_BORDER` | `#D2D2D8` | 网格线 |
| `C_GRAY` | `#C7C7CC` | 被支配点 |
| `C_SUCCESS` | `#2A8A61` | 性能地板、等待方案 |
| `C_WARNING` | `#E09500` | 超支持期边框 |
| `C_ERROR` | `#F24B4B` | 被支配语义 |

## 2. 字体

### 2.1 字体栈

| 角色 | 字体栈 | 降级链 |
|------|--------|--------|
| 显示标题 | `DM Sans` | `-apple-system, SF Pro Display, PingFang SC, sans-serif` |
| 正文 | `Inter` | `-apple-system, SF Pro Text, PingFang SC, Microsoft YaHei, sans-serif` |
| 等宽 | `JetBrains Mono` | `SF Mono, Consolas, monospace` |

> **小程序约束**：无法引入外部字体 CDN。小程序内正文使用系统默认字体（`-apple-system, PingFang SC`），仅在 HTML 报告中加载 DM Sans / Inter / JetBrains Mono。

### 2.2 字号层级

| Token | px | 字重 | 行高 | 用途 |
|-------|-----|------|------|------|
| `display` | 56 | 700 | 1.1 | 首屏大标题 |
| `h1` | 40 | 700 | 1.2 | 页面主标题 |
| `h2` | 32 | 600 | 1.25 | 区域标题 |
| `h3` | 24 | 600 | 1.3 | 卡片标题 |
| `h4` | 20 | 600 | 1.4 | 小节标题 |
| `lead` | 18 | 400 | 1.7 | 引导文 |
| `body` | 16 | 400 | 1.6 | 正文 |
| `caption` | 12 | 400 | 1.5 | 注解、徽章 |
| `mono` | 14 | 400 | 1.6 | 数值、代码 |

**字重口诀**：标题用 600，大标题用 700，正文用 400。字重不超过 700。移动端最小字号 14px，桌面端最小 12px。

## 4. 圆角

越大的容器拥有越柔和的圆角，形成从控件到页面的自然层级。

| Token | px | 用途 |
|-------|-----|------|
| `radius-sm` | 8 | 小控件、柱状图柱条 |
| `radius-md` | 12 | 按钮、导航项 |
| `radius-lg` | 16 | 表格、中等容器 |
| `radius-xl` | 20 | 标准卡片、突出面板 |
| `radius-full` | 9999 | 徽章、药丸形标签 |

> **小程序持有期按钮**例外：使用灰色（`#86868F` / `#D1D1D6` / `#F5F5F7`），不使用品牌蓝。

---

## 5. 阴影 / 层级

全部使用略带蓝调的深灰 `rgba(29,29,31, …)` 作为投影色，避免纯黑带来的生硬感。

| Token | CSS | 用途 |
|-------|-----|------|
| `shadow-1` | `0 1px 2px rgba(29,29,31,0.06), 0 1px 1px rgba(29,29,31,0.04)` | 卡片静息态 |
| `shadow-2` | `0 4px 8px -2px rgba(29,29,31,0.08)` | 卡片 hover |
| `shadow-3` | `0 8px 24px -8px rgba(29,29,31,0.14)` | 浮层、下拉 |
| `shadow-4` | `0 16px 40px -12px rgba(29,29,31,0.20)` | 模态框 |
| `shadow-5` | `0 24px 60px -20px rgba(29,29,31,0.26)` | 全屏遮罩 |

**哲学**：几乎感觉不到，但能区分层级。不堆叠厚重阴影。

## 7. 动效

| 属性 | 值 |
|------|-----|
| 过渡时长 | `0.15s` |
| 过渡属性 | `background, filter` |
| hover 反馈 | `filter: brightness(0.97)` |
| 缓动 | 默认 `ease`（不使用 spring / bounce） |

**禁止**：渐变动画、3D 翻转、弹性回弹。复制方案的高亮动画例外（`copy-highlight` 1.2s 蓝色高亮 → 微放大 → 淡出恢复）。

## 8. 文案语调

| 维度 | 规则 |
|------|------|
| 语言 | 中文优先 |
| 标题 | 2-4 字名词短语（如「月度销售报告」「关键指标」） |
| 操作按钮 | 「动词 + 对象」（如「导出报告」「查看详情」） |
| 状态标签 | 两字简短词（如「进行中」「已完成」「需注意」） |
| emoji | 不使用 |
| 数字说明 | 克制（如「本月」「较上月」即可，不展开长句） |
| 语气 | 干净、沉稳、专业、略带友好 |

---

## 11. 禁止事项

- 不用深色 / 渐变背景，不用斑马纹表格，不用多层阴影叠加
- 不引外部字体 CDN（小程序内），不引 Tailwind / Bootstrap 等 UI 框架
- 不新增语义色，不让成功绿与品牌蓝争抢
- 不用渐变填充、不用 3D 效果、不用动态动画（除 tooltip 外）
- 前沿点 / 主数据线永远是品牌蓝 `#007AFF`，被支配点用灰色半透明
- 超支持期边框用 `C_WARNING`，不用红色（红色留给「被支配」语义）
- 长持有期（>36 月）的点用 `opacity: 0.6` 标注预测置信度低
