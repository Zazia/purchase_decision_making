## MODIFIED Requirements

### Requirement: 新增自定义方案

方案编辑器 SHALL 允许用户新增自定义方案，输入机型名/芯片/内存/存储/买入时机/买入价/持有期。持有期 MUST 以可多选的勾选按钮呈现（选项覆盖 1 / 1.5 / 2 / 3 / 4 / 5 年），一次添加 MUST 为每个勾选的持有期各生成一个方案点并归入同一方案组（组内持有期变体展示与快照方案一致）；未勾选任何持有期时 MUST 拒绝提交并提示。新增方案的机型属性 MUST 能被引擎用于重算月均成本与性能满足度；无法解析芯片/品类的方案 MUST 即时提示并拒绝参与重算。新增方案在表格与图表中 MUST 标注「自添加」。

#### Scenario: 新增多持有期方案

- **WHEN** 用户新增一行：机型「M2 Mac mini」、芯片「M2」、内存 16G、存储 256G、二手、买入价 2600、勾选持有 2 / 3 / 4 年
- **THEN** 主列表出现一个标注「自添加」的方案组，持有期按钮显示 3/3，展开可分别排除个别持有期，重算后每个持有期变体的月均成本由引擎按各自持有期折旧计算

#### Scenario: 未勾选持有期被拒

- **WHEN** 用户未勾选任何持有期点击「添加」
- **THEN** toast 提示「请至少勾选一个持有期」，表单保持不关闭

#### Scenario: 新增不可解析方案被拒

- **WHEN** 用户新增一行但芯片名无法在引擎基准表中匹配
- **THEN** 该行提示「无法识别该芯片，无法重算」，不参与帕累托重算

### Requirement: 自添加方案编辑

自添加方案组（含复制产生的自添加副本组）SHALL 在行操作区提供编辑入口，点击后打开与新增一致的表单并进入编辑模式：表单 MUST 预填该组的机型名/芯片/内存/存储/买入时机/买入价（买入价优先带出行内改后价），持有期勾选状态 MUST 等于该组当前持有的持有期变体（组内存在选项之外的持有期时 MUST 并入选项列表）。保存时公共字段 MUST 整组生效，持有期按勾选结果增删方案点（新增点继承分组副本标记，删除点同步移出暂不考虑列表），已有点的排除/暂不考虑状态 MUST 保持；买入时机改变时渠道与国补 MUST 重置为对应默认值，不变时保留现值。取消 MUST 不产生任何数据变更。

#### Scenario: 编辑回填并修改机型名

- **WHEN** 用户点击某自添加方案组的编辑图标，将机型名从「M2 Mac mini」改为「M2 Mac mini (朋友机)」并保存
- **THEN** 组内全部持有期变体的机型名更新，分组不变，月均成本在重算后按新配置计算

#### Scenario: 编辑增删持有期变体

- **WHEN** 用户编辑持有期为 3 年的自添加方案组，改为勾选 2 / 3 / 5 年并保存
- **THEN** 组内新增 2 年与 5 年两个变体（参与重算），持有期按钮显示 3/3；若某变体原处于「暂不考虑」，被取消勾选后从暂不考虑列表彻底移除

#### Scenario: 编辑切换买入时机重置渠道

- **WHEN** 用户编辑自添加方案组，将买入时机从「二手」改为「新品」并保存
- **THEN** 组内渠道重置为「京东」并默认勾选国补；改回「二手」时渠道重置为「闲鱼」且国补取消

#### Scenario: 取消编辑

- **WHEN** 用户在编辑模式修改字段后点击「取消」
- **THEN** 表单关闭，方案数据无任何变更（可通过撤销栈状态确认无新快照）
