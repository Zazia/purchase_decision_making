## MODIFIED Requirements

### Requirement: 决策树引导式表单

小程序 SHALL 提供 5 步决策树：品类 → 预算 → 持有期 → 新品/二手 → 性能地板。每步 MUST 包含「不确定」选项。

**持有期步骤语义变更**：持有期步骤 SHALL 改为多选（2/3/4/5 任选 N 个），不再是单选。新增「都看看持有期」快捷项，点击后默认勾选 2/3/4/5 全集。多选结果以逗号分隔传 URL query。用户 MUST 至少选 1 个才能进入下一步。

**「都看看」买入时机语义变更**：「都看看」选项的 `value` MUST 为 `'both'`（不再是 `'used'`）。当用户选「都看看」时，引擎 MUST 同时生成新品与二手候选并在同一帕累托前沿上比较。

#### Scenario: 完整决策路径（多选持有期）

- **WHEN** 用户依次选择「Mac mini」「5000」「2年+3年+4年」「都看看」「0.7」
- **THEN** 进入结果页，URL query 包含 `holdingYears=2,3,4&buyTiming=both`，引擎用上述参数计算帕累托前沿，候选点同时包含新品与二手

#### Scenario: 持有期「都看看」快捷项

- **WHEN** 用户在持有期步骤点击「都看看持有期」快捷项
- **THEN** 2/3/4/5 全部勾选，可继续下一步或取消勾选

#### Scenario: 持有期至少选 1 个

- **WHEN** 用户取消所有持有期勾选，点击下一步
- **THEN** 下一步按钮禁用或提示「至少选 1 个持有期」

#### Scenario: 选择「不确定」分支

- **WHEN** 用户在某一步选择「不确定/帮我选」
- **THEN** 显示「AI 顾问功能开发中，已为您使用默认参数」提示，并使用该品类的默认参数继续流程；MUST NOT 阻塞主路径

#### Scenario: 「都看看」实际生成新品+二手候选

- **WHEN** 用户选「都看看」买入时机，品类为 Mac mini
- **THEN** 结果页的候选方案列表 MUST 同时包含 `buyTiming='new'` 与 `buyTiming='used'` 的方案；帕累托图 MUST 同时显示新品与二手的点

### Requirement: 引擎调用与结果展示

结果页 SHALL 调用 `apple-value-engine` 计算帕累托前沿，展示结论先行的推荐区间（非劣方案列表 + 月均成本范围），下方展示帕累托图。推荐区间 MUST 按「月均成本从低到高」排序，每个方案 MUST 显示机型、买入时机、持有期、月均成本、性能满足度。

**候选类型展示**：结果页 MUST 根据方案的 `candidateType` 渲染不同徽章：
- 类型 A（现在买）：无额外标注
- 类型 B（等新品买新品）：橙色「等新品后」徽章
- 类型 C（等新品后买降价老款）：橙色「等新品降价」徽章

**性能地板语义变更**：性能地板 SHALL 仅作为图上参考线与推荐区间内的「达标/低于地板」徽章标注，MUST NOT 用于过滤候选。低于性能地板的候选 MUST 保留在结果页与图表中可见。

#### Scenario: 展示非劣方案（含类型 B/C）

- **WHEN** 引擎返回 5 个前沿点，其中 2 个为类型 A、1 个类型 B、2 个类型 C
- **THEN** 结果页顶部列出 5 个方案，按月均成本升序，类型 B/C 方案 MUST 显示对应橙色徽章

#### Scenario: 空结果兜底（简化）

- **WHEN** 用户约束过严导致推荐区间为空（如预算 1000 买 Mac Studio）
- **THEN** 显示「当前预算内无非劣方案，建议放宽预算」，并给出放宽预算 ×2 后的最近可行方案；MUST NOT 再执行「放宽性能地板至 0」那一轮（性能地板已不过滤）

### Requirement: 帕累托图渲染

结果页 SHALL 用 ec-canvas 渲染静态帕累托散点图，横轴月均成本、纵轴性能满足度。MUST 关闭 tooltip 与缩放交互，点击点位 MUST 跳转该方案详情页。

**图表标注增强**：
- 推荐区间 MUST 用半透明色带（markArea）覆盖 cost ∈ [lowerCost, upperCost] 区间，让用户看到「我的预算在全景中的位置」
- 性能地板 MUST 用水平虚线标注
- 预算上限 MUST 用垂直虚线标注（若用户设了预算）
- 前沿点 MUST 高亮（实心+品牌色），被支配点 MUST 灰显但加细描边让位置可见
- 推荐区间内的前沿点 MUST 用主品牌色 + 边框，区间外的前沿点用次级品牌色

**候选类型形状区分**：
- 类型 A：实心圆（现有）
- 类型 B：三角形（向上）
- 类型 C：菱形
- 类型 B/C MUST 用次级品牌色（如 `#5AC8FA` 浅蓝）+ 半透明（标注预测置信度低）

#### Scenario: 推荐区间色带可见

- **WHEN** 引擎返回推荐区间 lowerCost=80, upperCost=120
- **THEN** 帕累托图 MUST 在 x 轴 [80, 120] 区间绘制半透明色带（`--accent-soft` 30% 透明度）

#### Scenario: 候选类型形状区分

- **WHEN** 引擎返回的候选包含类型 A、B、C 三类
- **THEN** 类型 A 用实心圆品牌蓝，类型 B 用三角形浅蓝半透明，类型 C 用菱形浅蓝半透明；图例 MUST 新增「等新品方案」项

#### Scenario: 被支配点位置可见

- **WHEN** 引擎返回 5 个前沿点 + 8 个被支配点
- **THEN** 帕累托图中 5 个前沿点为实心品牌色，8 个被支配点为浅灰 + 细描边（borderWidth: 1），点击被支配点 MUST 也能跳转详情页

#### Scenario: 点击跳详情

- **WHEN** 用户点击图中某点（前沿或被支配）
- **THEN** 跳转到方案详情页，展示该方案的完整成本分解（买入价/预期残值/维修成本/持有月数/性能满足度计算/候选类型/等待月数/系统支持期风险）

### Requirement: 方案详情页展示

详情页 SHALL 展示该方案的完整成本分解与性能满足度计算，新增候选类型、等待月数、预测价标注、系统支持期风险标注。

#### Scenario: 类型 B/C 详情展示

- **WHEN** 用户点击类型 B 候选点进入详情页
- **THEN** 详情页 MUST 显示「等待月数：N 个月」卡片、「买入价：¥XXXX（预测值）」徽章、候选类型说明

#### Scenario: 系统支持期风险标注

- **WHEN** 方案的 `systemSupportRisk='exceeded'`，`systemSupportExceedMonths=12`
- **THEN** 详情页 MUST 显示橙色风险卡片「⚠ 持有期末超出系统支持期 12 月」，列出具体风险（无法获取安全更新、新软件可能不兼容），但 MUST NOT 排除该方案

## ADDED Requirements

### Requirement: 端内报告页

小程序 SHALL 新增 `pages/report/` 报告页，从结果页底部「查看完整报告」入口进入。报告页结构 SHALL 对齐 skill 路径产出的 HTML 报告，做以下简化：

- 报告头部（标题 + 元信息：品类/预算/分析日期/SOP 版本）
- 结论卡（一句话结论 + 推荐方案摘要）
- KPI 行（4 卡：最佳月均成本 / 最佳性能 / 预算内买入价 / 当前同品类新品价）
- 预警 alert（v3.8 宏观事件 + 发布时间偏差提示，橙色）
- 推荐方案表（含推荐理由列）
- 全候选方案表（含被支配点 + 帕累托状态徽章 + 系统支持期标注 + 候选类型标注）
- 帕累托前沿图（复用 `pareto-chart` 组件）
- 宏观因素摘要（v3.8 触发的机制清单，可展开/收起）
- 数据置信度表（价格来源 + 置信度等级）
- 更新提示（触发重新分析的条件 + 下次建议分析时间）

**简化项**：MUST 移除月均成本曲线图（次要）；MUST NOT 引入外部 CSS/JS 框架；MUST 复用 `design_tokens` 作为 CSS 唯一权威源。

**全候选方案表折叠**：表格默认折叠，仅渲染前 20 行 +「查看全部 N 个方案」按钮，点击展开全部。

**导出与分享**：报告页 MUST 支持「导出为 HTML 文件」按钮，用 `wx.getFileSystemManager().writeFile` 写入单文件 HTML 到临时目录，文件名格式 `YYYY-MM-DD-{品类}-决策报告.html`；MUST 支持 `wx.shareFileMessage` 转发文件。

#### Scenario: 从结果页进入报告页

- **WHEN** 用户在结果页点击「查看完整报告」
- **THEN** 跳转到 `pages/report/report`，报告页从 `app.globalData` 读取引擎结果与决策参数，渲染完整报告

#### Scenario: 全候选方案表折叠

- **WHEN** 引擎返回 48 个候选点
- **THEN** 报告页全候选方案表默认显示前 20 行 +「查看全部 48 个方案」按钮，点击后展开全部

#### Scenario: 导出 HTML 报告

- **WHEN** 用户点击「导出为 HTML 文件」
- **THEN** 调用 `wx.getFileSystemManager().writeFile` 写入 `${wx.env.USER_DATA_PATH}/2026-08-07-mac-mini-决策报告.html`，写入成功后 toast「报告已保存」并提示可用 `wx.shareFileMessage` 转发

#### Scenario: 报告页文案合规

- **WHEN** 提审小程序
- **THEN** 报告页全站文案 MUST NOT 出现「推荐购买/立即下单/下单/最低价/性价比之王」字样；类型 B/C 预测价 MUST 标注「预测值」+ 置信度等级；MUST NOT 出现外部购买链接
